# KeywordTrip — 앱인토스 개발 브랜치

앱 ID: `keytrip`. 이 문서는 개발 준비용이며 앱인토스 등록·심사 완료를 뜻하지 않습니다.

## 구현 계획
- 기존 `assets/data.js` 및 `assets/finder.js`의 추천 데이터·필터를 재사용합니다.
- 토스 전용 화면에서 시기, 동행, 취향, 예산을 입력받고 결과 3곳을 제시합니다.
- 예산은 실시간 항공권 가격이 아니라 서울 출발 1인 4~5일 추정 범위이므로 근거와 한계를 표시합니다.
- Trip.com 제휴 링크·인앱 광고·외부 이동은 앱인토스 정책 확인 전까지 비활성화합니다.
- 연락처 수집, 결제, 로그인은 MVP에서 제외합니다.
- SDK 3.x 및 .ait 빌드 규격을 공식 개발 문서와 샌드박스에서 확인합니다.
